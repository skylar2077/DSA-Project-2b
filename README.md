# DSA-Project-2b
Instructions Prior to Cloning Repo:
1. Check if Git LFS is installed by running commands: 
    winget install GitHub.GitLFS
    git lfs install

Instructions for installing required libraries:
1. Make sure Python 3.12 is installed or install it with command: winget install Python.Python.3.12 (Windows only)
2. Navigate to the root directory of the project in the terminal
3. Create a virtual environment with command: py -3.12 -m venv venv
4. Go into the created venv/Scripts folder and run Activate.ps1
5. Download required libraries with command: pip install -r requirements.txt

How to run the website:
1. Navigate into the src folder of the project in terminal
2. Type into terminal: python server.py
3. In a web browser or within IDE, search local address 127.0.0.1 to open website
